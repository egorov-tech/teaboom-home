# Teaboom — главная + карточка (демо одной системы)

Вёрстка главной и принятой карточки товара интернет-магазина чая Teaboom (teaboom.ru,
ООО «Кассиопея») для обсуждения с заказчиком и его UI/UX-дизайнером. Одна визуальная система:
клик по товару в витрине ведёт в нашу `product.html` (пока «Ананасовый улун» — погружение
в один продукт). Каталог, корзина и остальные страницы в этот заход не рисовались.

**Главная:** https://egorov-tech.github.io/teaboom-home/
**Карточка в этой же системе:** https://egorov-tech.github.io/teaboom-home/product.html
**Эталон (не менять):** https://egorov-tech.github.io/teaboom-product-card/
([репозиторий эталона](https://github.com/egorov-tech/teaboom-product-card))

## Как открыть

Сборка не нужна: склонировать и открыть `index.html`.

```bash
git clone https://github.com/egorov-tech/teaboom-home.git
cd teaboom-home
open index.html          # или python3 -m http.server 8000
```

Единственная внешняя загрузка — шрифты Google Fonts. Без сети страница остаётся на системном
гротеске. Скомпилированный `assets/css/main.css` лежит в репозитории; пересборка стилей:

```bash
npx sass assets/scss/main.scss assets/css/main.css --no-source-map --style=expanded
npx sass assets/scss/product.scss assets/css/product.css --no-source-map --style=expanded
```

`index.html` и `product.html` собираются из шаблонов в `tools/` и данных `data/products.json`.
После правки цен, товаров или баннеров:

```bash
python3 tools/build_index.py     # нужен Pillow: pip install pillow
```

## Что взято с teaboom.ru

Всё содержимое снято с живой главной 26.10.2026: тексты, меню, телефоны, режим работы, категории,
баннеры, товары, фасовки, артикулы и цены. Полный инвентарь с адресами — в [CONTENT.md](CONTENT.md),
данные товаров в машинном виде — в [data/products.json](data/products.json). Тексты, отзывы, акции
и характеристики не придумывались.

- **Изображения** скачаны с CDN магазина (`media.teaboom.ru`) и лежат в `assets/images` в двух форматах:
  WebP и JPEG-фолбэк, плюс узкие версии для телефонов (`-480` у баннеров, `-280` у товаров).
- **Текст на баннерах** нарисован в самих картинках; для `alt` он переписан с изображения.
- **Логотип, favicon и фоновый паттерн** — те же ассеты teaboom.ru, что и в принятой карточке.
- **Юрлицо и ИНН** в подвале взяты из договора-оферты на сайте (раздел 16).

## Блоки страницы

Порядок — как на живой главной:

1. **Шапка** — логотип, телефон, e-mail, режим работы, демо-корзина со счётчиком; меню с выпадающим
   «Каталогом» на 20 категорий, «Подарки», «Прайслист», «Отзывы», «Контакты»; поиск.
2. **Первый экран** — меню «Категории» (9 пунктов с миниатюрами) и 12 баннеров магазина.
3. **Преимущества** — те же три пункта с сайта; в демо сильнее бренд-акцент (жёлтая линия
   сверху полосы, иконки на лёгком жёлтом фоне, заголовки Oswald).
4. **«Рекомендуем»** — 8 товаров с сайта плюс первым «Ананасовый улун» для демо: фасовки, цены,
   скидка в %, артикул, «В корзину». У ананасового улуна внутри карточки свайп по 4 фото
   (остальные товары на сайте имеют одно фото — свайпа нет). Название и фото ведут на
   `product.html`, не на боевой сайт.
5. **Текст о магазине** — шесть абзацев с сайта.
6. **Подвал** — контакты, «Компания», «Документы», «Покупателям», соцсети, юрлицо.

Меню, категории и подвал по-прежнему ведут на живой teaboom.ru. Поиск — на `teaboom.ru/search`.
Товары витрины — в нашу карточку.

## Решения, которые стоит обсудить с дизайнером

- **Первый баннер.** На сайте слайдер открывается баннером Telegram-канала (синий, не про чай).
  В демо первым стоит «Анчан — синий чай из Таиланда, хит сезона», остальные идут в порядке сайта.
  Какой баннер главный — решение магазина.
- **Слайдер без автоплея.** Баннеры листаются стрелками, свайпом или клавишами ← →. На телефоне
  край следующего баннера выглядывает справа, чтобы было видно, что ряд листается.
- **Один `h1`.** На сайте их два («Рекомендуем» и заголовок текста о магазине). Здесь `h1` один,
  визуально скрытый в начале `main`: «Интернет-магазин чая в Москве «Чайный Бум»». «Рекомендуем»
  стал `h2`, а у текста о магазине заголовком служит его первая фраза с сайта.
- **Скидка в процентах.** Сайт пишет только «Скидка!». Здесь бейдж показывает процент, и он
  считается из двух цен сайта для выбранной фасовки, а не задаётся вручную.
- **Наличие не показано.** В разметке сайта оно есть, но скрыто от посетителя; здесь тоже не выводится.
- **Иконки преимуществ.** На сайте это PNG 42×33 из темы; здесь нарисованы контурные SVG того же смысла,
  чтобы не расплывались на ретине; полоса perks сильнее выделена брендом, чем на живом сайте.
- **Одна карточка на все клики витрины.** Пока все товары ведут в `product.html` с «Ананасовым улуном»,
  чтобы заказчик и дизайнер погрузились в один продукт в той же оболочке, что и главная.
- **Свайп фото в карточке витрины.** Как у многих магазинов: листание без перехода. На живой главной
  у рекомендованных товаров по одному кадру; свайп показан на «Ананасовом улуне».
- **Полёт в корзину.** На главной и в `product.html` одна анимация: фото по дуге в бейдж корзины,
  затем bump счётчика. Счётчик общий на вкладку (`sessionStorage`). Код — `assets/js/cart.js`.
- **Аудит.** Замечания по компонентам/CSS/масштабированию — в [AUDIT.md](AUDIT.md).
- **Уведомление о сбоях Яндекса**, которое висело в шапке 19.10, на 26.10 с сайта снято и сюда
  не перенесено.
- **Фасовки ниже, чем на карточке.** Чипы фасовок на главной — 64 px по высоте, а не 76 px:
  на витрине восемь товаров, и при 76 px каждая карточка вырастала почти на экран телефона.
  Зона нажатия при этом с запасом больше 44 px.

## Чего не хватило на сайте

Подробно — в [GAPS.md](GAPS.md). Коротко:

- на главной нет отзывов, поэтому блока отзывов нет;
- нет акций с условиями и сроками — есть только фраза «Множество скидок каждый день»;
- текст баннеров существует только внутри картинок;
- живой поиск с подсказками, корзина и вход работают на сервере магазина и со статики недоступны:
  корзина здесь — демо-счётчик, вход не показан.

## Вёрстка

- HTML5, SCSS, vanilla JS. Без Bootstrap, jQuery, React и готовых шаблонов магазина.
- Палитра, шрифты, шапка, чипы фасовок и кнопка — продолжение принятой карточки:
  холст `#fefcef`, бумага `#fff`, чернила `#1b1b1b`, жёлтый `#f5d730`; Oswald для заголовков
  и цен, Open Sans для текста; радиусы 3–6 px, шаг отступов 4/8/12/16/24/32/48/72.
- Жёлтой рамки и линии вокруг главного изображения нет. Полноэкранной заставки с листом нет.
- Сетка на CSS Grid, размеры через `clamp()`. Длина строки текста о магазине ограничена 68 знаками.

| Ширина | Раскладка |
|---|---|
| ≥ 1060px | категории слева от баннера; товары в 4 колонки; контакты в строке с логотипом |
| 600–1059px | категории — лента над баннером; товары в 2 колонки; контакты строкой ниже логотипа |
| < 600px | то же, товар — фото слева от названия, фасовки и цена под ними; у корзины только иконка и счётчик |

## Доступность

- один `h1`, заголовки без пропусков уровней; `header`, `nav`, `main`, `footer`;
- skip-link «Перейти к содержимому» ведёт к `main`;
- видимый `:focus-visible` на всём интерактивном; с клавиатуры проходит вся страница;
- в порядке Tab только баннер, который сейчас на экране, а не все двенадцать;
- «Каталог» — кнопка с `aria-expanded`: Tab с неё ведёт в список категорий, с последней категории —
  к следующему пункту меню; Esc закрывает и возвращает фокус на кнопку; клик снаружи закрывает;
- фасовки — нативные radio в `fieldset` с `legend`, работают стрелки; цена объявляется через `aria-live`;
- добавление в корзину объявляется скринридеру (`role="status"`);
- у картинок `alt` по содержимому: у баннеров — их текст, у декоративных миниатюр — пустой;
- контраст текста к фону от 5:1; оранжевый «Подарков» (3.8:1) оставлен только у иконки,
  текст пункта набран чернилами;
- зоны нажатия от 44 px, кнопка «В корзину» — 52 px, стрелки слайдера и поиск — 48 px. Исключения:
  строка категории в карточке товара — 24 px (минимум WCAG 2.2 AA для мелкой вторичной ссылки)
  и ссылка на teaboom.ru внутри предложения в подвале (ссылки в тексте WCAG не ограничивает);
- в лентах меню и категорий элемент в фокусе докручивается в видимую область;
- при `prefers-reduced-motion` слайдер переключается без прокрутки-анимации, анимации отключены,
  всё остаётся рабочим;
- масштабирование страницы не запрещено.

## Скорость

- первый баннер: `width`/`height`, `fetchpriority="high"`, `preload` с `imagesrcset`, WebP + JPEG;
- остальные 11 баннеров не грузятся вместе со страницей: `home.js` подставляет их источники,
  когда слайдер до них доходит (у картинок в горизонтальной ленте `loading="lazy"` загрузку
  не откладывает). Без JS виден только первый баннер;
- всё ниже первого экрана — `loading="lazy"`; узкие версии изображений через `srcset`/`sizes`;
- Google Fonts подключаются после события `load`; до этого текст набран системным гротеском
  (без JS шрифты подключает `<noscript>`). Сдвиг вёрстки при смене шрифта — CLS 0.004;
- вес страницы при загрузке — 514 КБ; без заставки, без автоплея, без чужого JS.

## Движение

Только в ответ на действие: прокрутка слайдера, нажатие кнопок (`scale(0.97)` на `:active`),
короткий отскок счётчика корзины. Переходы указаны по конкретным свойствам, 150–220 ms, ease-out.
Hover включается только на устройствах с мышью (`@media (hover: hover)`), и у каждого живого
элемента есть видимое состояние без наведения. Анимации появления секций нет.

## SEO и семантика

- `meta robots: noindex, nofollow` — демо закрыто от индексации; `canonical` на teaboom.ru не ставится;
- JSON-LD: `ItemList` из восьми `Product` с `AggregateOffer` (минимальная и максимальная цена
  фасовок, данные с сайта) и `Organization` — по той же схеме, что у сайта;
- цены форматируются через `Intl.NumberFormat('ru-RU')`: целые суммы без копеек, дробные — с двумя знаками.

## Что проверено

Проверено 26.10.2026 в Chromium (Playwright) на локальном сервере.

- **Горизонтальная прокрутка:** нет на 320, 375, 768, 1024 и 1440 px
  (`scrollWidth` равен ширине окна).
- **Телефон, 375 px, касания:**
  - ← → и свайп баннеров, счётчик следует за слайдом;
  - лента меню и лента категорий листаются;
  - «Каталог» открывается и закрывается тапом снаружи;
  - выбор фасовки пересчитывает цену, старую цену, процент и артикул;
  - «В корзину» увеличивает счётчик и объявляет добавление.
- **Клавиатура, 1440 / 768 / 375 px:** skip-link переводит фокус в `main`; проход по Tab вперёд
  и назад через шапку, меню, категории и баннер — фокус виден и не уходит за край экрана;
  «Каталог» через Enter, Tab/Shift+Tab, Esc; стрелки слайдера по кругу; стрелки в группе фасовок;
  поиск по Enter отправляет `teaboom.ru/search?q=…`.
- **Проверка на шаблонность** (redesign-existing-projects): из чек-листа применено только
  `text-wrap: balance/pretty` для заголовков и абзацев; шрифты, палитра, белые панели товаров,
  три преимущества и четыре колонки подвала оставлены — их задают бриф и содержимое сайта.
- **`prefers-reduced-motion`:** слайдер переключается мгновенно.
