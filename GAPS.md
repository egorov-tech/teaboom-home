# Чего не удалось снять с teaboom.ru

Всё перечисленное на страницу не добавлено или добавлено только в той мере, в какой данные есть на сайте.

| Что | Почему пробел | Как поступили на странице |
|---|---|---|
| Отзывы покупателей на главной | На главной нет ни одной цитаты, только пункт меню «Отзывы» | Блока отзывов нет, ссылка в меню ведёт на `teaboom.ru/shop_reviews/` |
| Акции с условиями и сроками | Есть только общая фраза «Множество скидок каждый день» и бейджи «Скидка!» у товаров | Отдельного блока акций нет; скидка показана у тех четырёх товаров, где сайт отдаёт старую цену |
| Процент скидки | Сайт пишет только «Скидка!» | Процент считается из двух цен с сайта (старая и новая), не вводится вручную |
| Наличие товара | В разметке есть («Много», «Мало»), но скрыто от посетителя (`d-none`) | Не показываем, чтобы не публиковать данные, которые магазин сам скрыл |
| Текст на баннерах | Нарисован в картинке, в HTML его нет | Переписан с изображений в `alt`; сами баннеры показаны как есть |
| Живой поиск (подсказки) | Работает через внутренний `/livesearch`, недоступный со статики | Форма поиска отправляет запрос на `teaboom.ru/search?q=` — как кнопка «Найти» на сайте |
| Корзина, вход, оформление заказа | Требуют сервер магазина | Корзина — только демо-счётчик на странице; вход не показываем |
| Несколько фото у товаров из «Рекомендуем» | У всех восьми на карточке товара только одно фото в блоке `product-img`; остальные картинки на странице — «похожие товары» | Свайп в витрине включён только у «Ананасового улуна» (4 кадра из принятой карточки). Остальные карточки — одно фото |
| «Ананасовый улун» в блоке «Рекомендуем» | На живой главной его нет | Добавлен первым в витрину демо, чтобы клик вёл в нашу `product.html` и можно было пощупать свайп галереи |
| Векторные иконки преимуществ | На сайте только PNG 42×33 из темы | Нарисованы простые контурные SVG того же смысла (фургон, кошелёк, щит) — декоративные, `aria-hidden` |
| Описание товаров, вес нетто, состав | На главной не выводятся | Не выводим, только название, категория, фасовки и цены |
| Уведомление о сбоях Яндекса | Было 19.10, на 26.10 снято с сайта | Не переносим |
| Мобильная иконка входа `/login` | Ведёт в личный кабинет, который в этот заход не входит | Не показываем |
