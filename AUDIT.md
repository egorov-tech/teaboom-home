# Технический аудит демо Teaboom (главная + карточка)

Дата: 2026-10-26. Объект: `egorov-tech/teaboom-home` (главная + `product.html`) и эталон
`egorov-tech/teaboom-product-card` (не менять). Аудит — взгляд senior/team lead на готовность
к коммерческому развитию, не только «совпадает ли с ТЗ».

## Критические проблемы

1. **Дублирование оболочки карточки поверх shell главной (было).** В `product.css` подтягивался
   `_pdp-chrome.scss` со старыми `.menu` / `.search` эталона — на карточке ломалась единая шапка.
   **Исправлено:** chrome оставлен только под steep; меню/поиск/корзина — один `_shell.scss`.
2. **Разный UX «В корзину».** На эталоне — полёт фото + bump; на главной был только bump.
   **Исправлено:** общий `assets/js/cart.js` (полёт, bump, счётчик в `sessionStorage` между страницами)
   + общие стили `.fly` / `.add`+`.cta`.
3. **Две кнопки покупки с разным поведением и стилем (`.add` / `.cta`).**
   **Исправлено:** `_cta.scss` — один визуальный контракт.

## Важные проблемы

1. **Два набора чипов фасовки.** Витрина (`_goods.scss` + `pack__chip`) и PDP (`_pdp-buy.scss` +
   `packs` / `pack__save`) — похожи, но не один компонент. Junior легко скопирует третий вариант
   в каталоге. Нужен параметризованный `PackPicker` (size: compact | full, showSave: bool).
2. **Два CSS-бандла без общего «kit»-слоя.** `main.css` и `product.css` делят tokens/shell/cta,
   но packs/price/gallery ещё нет. При каталоге 1000+ без UI Kit вырастет CSS Legacy.
3. **Все клики витрины → одна `product.html`.** Ок для демо погружения; для продакшена нужен
   роут/статическая генерация по slug, иначе SEO и кэш разъедутся.
4. **Цены и товары в JSON + генератор** — хорошо; но нет слоя «корзина/избранное» кроме демо.
   Настоящая корзина потребует API и выкинет текущий sessionStorage-счётчик.
5. **Галерея на главной.** У живых «Рекомендуем» с сайта по 1 фото; свайп только у демо-улуна.
   Масштабирование без реального multi-image API даст пустые карусели или чужие кадры.

## Рекомендации

| Вынести в UI Kit | Параметры |
|---|---|
| `Masthead` / `CatalogPanel` / `Search` / `CartBadge` | уже почти едины |
| `PerkStrip` | items[], accent: brand-line |
| `ProductTile` | gallery[], packs[], href |
| `PackPicker` | variants, density, showPer100g |
| `PriceBlock` | now, was, cut%, sku |
| `BuyButton` | `.add` / `.cta` уже сведены |
| `BannerCarousel` / `TileGallery` | общий scroll-snap + hydrate |
| `Footer` | колонки из данных |

Декомпозиция карточки (как есть по смыслу):

```
ProductPage
  ProductGallery (shot + thumbs)
  ProductInfo (category, title, summary, sku)
  PackPicker + PriceBlock + BuyButton
  ProductAbout (specs dl)
  ProductReviews
```

Вертикальный ритм и токены (`--step-*`, `--brand`, Oswald/Open Sans) уже заданы — не плодить
новые «магические» 18px/22px вне шкалы.

Адаптив: сетки 320–1440 проверены на главной; ultrawide >1600 — контент в `max-width: 1200`,
это ок, не растягивать витрину на всю ширину без решения дизайнера.

## Что уже сделано хорошо

- Контент с боевого сайта, без выдуманных характеристик.
- Токены и визуал продолжают принятую карточку.
- Генератор `tools/build_index.py` + `data/products.json` — один источник цен.
- A11y: skip-link, focus-visible, radio-фасовки, reduced-motion, live regions.
- Демо закрыто `noindex`; эталон карточки не ломается.
- Баннеры без автоплея; lazy/hydrate для скорости.
