## Важные проблемы — статус

| Было | Сейчас |
|---|---|
| Два набора чипов фасовки | Один PackPicker: `_packs.scss`, `packs--compact` на витрине |
| Нет kit-слоя packs/price | `_packs.scss` + `_price.scss` в обоих бандлах |
| Все клики → одна `product.html` | **Намеренно для демо погружения**; в проде — генерация/роуты по slug |
| Нет API корзины | Статика: демо-счётчик. Реальная корзина — отдельный этап |
| Multi-photo только у улуна | На teaboom у «Рекомендуем» по 1 кадру в `product-img`; чужие фото не подставляем. Свайп+авто у ананаса и баннеров |

## Автосвайп

- Баннеры: `data-autoplay="5000"`, пауза на hover/focus/touch и вне вьюпорта, off при `prefers-reduced-motion`,
  плюс видимая кнопка «Пауза / Продолжить» (WCAG 2.2.2 — у самодвижущегося контента должна быть остановка).
- Галереи фото (карточка витрины и `product.html`): автопрокрутки нет, только свайп, стрелки, точки
  и миниатюры. Вернуть можно атрибутом `data-autoplay` / константой `GALLERY_AUTOPLAY`, но тогда
  галерее тоже нужна кнопка паузы.

## Доводка 27.10

- Шапка: закреплён сам `<header>`, меню/поиск/«Каталог» вынесены следом. Компакт не меняет высоту
  (сдвиг `top` у sticky + трансформации) — нет скачков `scrollY` и сдвигов вёрстки. Раньше липкий ряд
  держался только ~200 px прокрутки (sticky внутри `<header>`), а на десктопе компакт раздувал шапку
  до 225 px и прокрутка прыгала на 146 px.
- `product.template.html`: убран продублированный хвост — каждый скрипт подключался дважды.
- `home.js`: при выключенном автоплее (reduced motion, галереи) листание падало с
  `autoplay?.nudge is not a function` — исправлено.
- Доступность: skip-link поверх липкой шапки, точки галереи 24×24, у миниатюр карточки есть имена.
- Отзывы на карточке помечены как пример (на teaboom.ru их у товара нет), рейтинг убран из JSON-LD.

## Что остаётся за рамками этого демо

- Отдельная `product/<slug>.html` на каждый SKU с полным контентом.
- Серверная корзина, избранное, ЛК, мультиязычность.
- Догрузка реальных multi-image с бэка, когда магазин отдаст больше одного кадра в галерее.
